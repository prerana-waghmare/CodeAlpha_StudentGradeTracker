Student Grade Tracker

Project Overview

The Student Grade Tracker is a Java-based console application developed as part of the CodeAlpha Java Programming Internship.

It helps users manage student marks and calculate important academic statistics.

Features

- Add student names and marks.
- Display all student records.
- Calculate average marks.
- Find the highest marks.
- Find the lowest marks.
- Validate marks between 0 and 100.

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner class

How to Run the Project

Step 1: Compile the program

Open the terminal in the project folder and execute:

javac StudentGradeTracker.java

Step 2: Run the program

java StudentGradeTracker
